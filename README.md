# Cleaning company feasibility analysis

Feasibility study for a home cleaning startup in Stockholm (RUT deduction segment): market size, competition, regulation, insurance, unit economics, recruitment strategy and differentiation analysis.

Published via GitHub Pages. The report is written in Swedish for the founding team.

- `index.html` — the full report as a single page
- Underlying research data, source list and the runnable unit economics model live in the private working folder (`RAPPORT.md`, `kallor.md`, `research/`, `kalkyl/unit_economics.py`)

All figures are sourced (85 sources, fetched 2026-08-18). Regulatory parameters (RUT deduction, employer fee reductions, benefit taxation) change frequently and should be re-verified before launch.
